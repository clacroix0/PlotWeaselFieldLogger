Plot Weasel Field Logger User Guide

Plain-language instructions for field collection, local data management, crew merging, backup, and export.

Current guide coverage:

  • Plot Weasel Field Logger v2.3.4, released September 21, 2026
  • Official Android APK: PlotWeaselFieldLogger_Ver2.3.4.apk
  • Downstream compatibility reference: Plot Weasel Desktop v2.3.3, a separately maintained Shiny R application

Plot Weasel Field Logger and Plot Weasel Desktop are developed for the BIA Division of Forestry, Branch of Forest Inventory & Planning.

Guide updated: September 22, 2026

What this guide is for: This guide explains what each app does, how to move through the screens, what files to export, and what to do when something looks wrong. It is written for someone who has never used the apps before.

Normal Workflow

  1. On Android field tablets, install and open the official v2.3.4 Android APK. Confirm the app header shows v2.3.4, Released September 21, 2026, and Local only.
  2. On Windows or Microsoft Surface devices, open the official offline PlotWeasel_Field_Logger.html file in Microsoft Edge.
  3. On an office computer or field tablet, use Plot Weasel Field Logger to enter the project name and build the project species pick list.
  4. Add any project-specific damage agents crews may need.
  5. Export a Project Setup JSON file and copy it to each receiving crew tablet.
  6. On each receiving tablet, import the Project Setup file, then enter that tablet's Crew Name and Crew ID.
  7. Use Plot Weasel Field Logger on each tablet to collect field data.
  8. At the end of the day or examination, each crew exports a Crew Package.
  9. Each crew also exports a Backup JSON for the active project at the end of each day and before any app update, uninstall, or Clear Device Data action. Export one Backup JSON for each saved project.
  10. On Android v2.3.4, verify exported files in My Files → Downloads → PlotWeasel.
  11. Back at the office, import all Crew Packages into one secured copy of Field Logger.
  12. Use Save Site, Tree, Woodland, Regen CSVs to create the combined reference, master-record, review, and regeneration files.
  13. Export Plot Weasel Desktop CSV to create PlotWeasel_upload.csv for point-sample tree analysis.
  14. Transfer the approved CSV files to the current Plot Weasel Desktop workflow. Follow Casey Sigg's official Desktop instructions for the hosted Shiny application.

Security reminder: Plot Weasel Field Logger stores its working data locally and can be used offline. Plot Weasel Desktop v2.3.3 is a separately hosted Shiny application. Uploading a CSV sends that file to the approved hosting environment for processing. Confirm that the current Desktop host, access controls, and data-handling process are approved before uploading sensitive tribal data.

Part 1: Plot Weasel Field Logger

Plot Weasel Field Logger is the field data-entry app. It is designed for Android field tablets, Samsung tablets, Microsoft Surface devices, secured Windows computers, and offline use. It stores data locally on the device until the user exports it.

How To Open Field Logger

There are two supported ways to open Field Logger: the recommended Android APK path for Android tablets, and the offline HTML path for Windows or Microsoft Surface devices.

Recommended Android APK Path

  1. Obtain the approved PlotWeaselFieldLogger_Ver2.3.4.apk file.
  2. When a release SHA-256 value is provided, verify the APK against that value before installation.
  3. Copy the APK to the Android tablet.
  4. Open Files, My Files, or the approved file manager.
  5. Tap the APK file.
  6. If Android asks, allow installation from that approved source, such as Files, My Files, Chrome, Drive, or the approved file manager.
  7. If v2.3.3 is already installed, install v2.3.4 over the existing app as an update. Do not uninstall the existing app first.
  8. Open Plot Weasel Field Logger from the app icon.
  9. Allow Location permission while using the app. Use Precise location if Android offers that option.
  10. Confirm the app header shows v2.3.4.
  11. Confirm the app header shows Released September 21, 2026.
  12. Confirm the app header shows Local only.
  13. Create a test project, close the app, reopen it, and confirm the project remains available.
  14. Test Project Setup, Crew Package, Backup JSON, Plot Weasel Desktop CSV, and the grouped Site, Tree, Woodland, Regen CSV export.
  15. Open My Files → Downloads → PlotWeasel and confirm the actual exported files exist.

Play Protect or unrecognized-app warning: Android may warn that a directly installed APK is unknown or was not installed from Google Play. Only proceed when the APK came from the approved Plot Weasel release source and, when available, its SHA-256 value matches the published value. This installation warning is separate from Field Logger's CSV and JSON export behavior.

Do not skip the storage and export checks: Before real field use, create a test project, close the app completely, reopen it, and confirm the test project is still there. Then export test files and confirm they are visible under Downloads/PlotWeasel. Restart the tablet and repeat the checks when possible.

Windows Or Microsoft Surface HTML Path

  1. Open PlotWeasel_Field_Logger.html in Microsoft Edge.
  2. If the computer asks what app to use, choose Microsoft Edge or the approved browser.

Best no-APK option: Use the normal Field Logger HTML or the single-file HTML version. In v2.3.3, both are self-contained with the app controls, style, icon, and FIA species list built into the file.

iPhone/iPad Note

For local files on iPhone or iPad, Safari and Chrome may treat the Field Logger HTML as a limited preview instead of a full app. If the page opens but Species, Trees, Regen, Add Plot, Aspect, or Slope Position do not respond, do not rely on that iPhone/iPad workflow for field collection until it has been separately tested.

Android Storage Mode Check

The app header may show a storage mode. Crews should understand the difference before entering real data.

Android Updates And Uninstalling

  • Before installing an updated APK, open each saved project and export a separate Backup JSON.
  • Confirm each backup exists under My Files → Downloads → PlotWeasel and copy it to an approved location.
  • Export any required Crew Packages.
  • Keep the existing application installed and install the new signed APK over it.
  • The updated APK must use the same Android application ID and signing key as the installed release and must have a higher Android version code.
  • Do not uninstall the app before backing up data. Uninstalling can remove locally stored projects.
  • APK installer files in Downloads can be deleted after installation. Deleting the installer file does not delete the installed app or its saved data.
  • If Android says App not installed during an update, stop before uninstalling anything. Confirm the signing key, application ID, and version code.
  • After updating, confirm the expected version and release date, confirm existing projects remain, and retest every export button.

Main Screen Areas

  • Projects: Open a saved project, start a new project, or delete the active project from that device.
  • Field Session: Enter the Project name, Crew Name, and Crew ID. Turn on Southwest Variant / Woodland Nested Plot when the project includes fixed-radius woodland plots.
  • Plots: Add a new plot and choose the current plot.
  • Site tab: Enter site-level reference information.
  • Species tab: Choose the point-sample tree and regeneration species list from the FIA master species list.
  • Trees tab: Enter trees tallied in the point sample.
  • Woodland tab: Enter fixed-radius woodland nested plot records. This tab appears only when Southwest Variant / Woodland Nested Plot is active.
  • Regen tab: Enter regeneration records.
  • Review tab: Check warnings and errors for site, tree, woodland, and regeneration records before exporting.
  • Export / Merge tab: Export project setup, field files, separate Woodland.csv records, backups, and crew packages. PlotWeasel_upload.csv contains point-sample tree records only.

Switch Between Projects

Field Logger can keep more than one project in the same browser on the same tablet. Use the Projects panel on the left side of the app.

  • Open Project: Choose a saved project from the dropdown. The dropdown shows the project name and record counts.
  • New Project: Starts a blank project while keeping old projects saved on the device. It keeps the current Crew Name and Crew ID, but starts with blank plots, trees, regen, and project species.
  • Delete Project: Deletes only the active project from that device.
  • Project box: Renames the active project. Existing records follow that rename.
  • Clear Device Data: Removes all saved projects from that browser on that device.

Before opening note: A single shared HTML file or generic home-screen icon cannot show which saved project will open before launch. After the app opens, the Projects panel shows the active project, the browser tab title includes the active project name, and the app address includes that project's ID. To make a project-specific shortcut, open Field Logger, switch to the project, then add or bookmark that page and name the shortcut after the project.

Set Up A Field Session

  1. Enter the Project name.
  2. Enter the Crew Name.
  3. Enter the Crew ID, if your team uses one.
  4. For Southwest woodland projects, select Activate Southwest Variant / Woodland Nested Plot. This displays the Woodland tab. Leave it unchecked when the project does not use woodland nested plots.
  5. Add the first plot number in the New plot # box and click Add.

Set Up The Species List

The app starts with an empty project species list. This is intentional. Each project can have its own species dropdown.

  1. Go to the Species tab.
  2. Search the FIA Master Species list by common name or FIA code.
  3. Select the species and click Add Species.
  4. Repeat until the project list has the species crews expect to use.
  5. Use Save Species List to save one editable species list on the device.
  6. Use Restore Saved List to reload that saved list later. Saving again overwrites the old saved copy.
  7. Use Clear Species List if you want to empty the project dropdown.

Adding species in the field: If a crew finds a point-sample tree or regeneration species that was missed, go back to the Species tab, search the FIA list, and add it. The species will then appear in the Trees and Regen dropdowns. The Woodland tab uses its own hardcoded Southwest woodland species list and is not controlled by the project species pick list.

Tree versus Woodland sampling: Some Southwest woodland species may overlap with species available in the project species list. The project lead must choose the sampling method before field collection. Use the Trees tab for DBH point-sample records or the Woodland tab for DRC fixed-radius records. Do not enter the same sampled tree in both tabs.

Set Up Damage Agents

The Species tab includes a Project Damage Agents list. Add project-specific damage agents there if the default choices are not enough.

  • Each tree record can store Damage Agent 1 and an optional Damage Agent 2.
  • Each regeneration record stores one damage agent.
  • None means that no damage agent was observed.
  • The value None is saved for form behavior but exports as a blank CSV field.
  • Broken Top remains available because it controls the live-tree Actual Height rules.
  • A tree cannot use the same named damage agent in both tree damage fields.
  • A damage agent already used by a saved tree or regen record cannot be removed from the project list.

Set Up A Project And Share It

Use Project Setup when it is faster to build the project once on an office computer or field tablet and send the same setup to several tablets.

  1. Open Field Logger on the office computer or field tablet that will be the source setup device.
  2. Enter the Project name.
  3. If the project uses fixed-radius woodland nested plots, select Activate Southwest Variant / Woodland Nested Plot.
  4. Go to the Species tab and build the point-sample tree and regeneration species pick list from the FIA Master Species list.
  5. Add any project damage agents that crews should see.
  6. Go to Export / Merge.
  7. Click Export Project Setup. This creates a JSON setup file.
  8. Copy that JSON setup file to each receiving tablet using an approved local transfer method.
  9. On each receiving tablet, open Field Logger, go to Export / Merge, and choose Import Project Setup.
  10. After import, enter the tablet's Crew Name and Crew ID.

What Project Setup includes: Project name, point-sample tree and regeneration species pick list, one saved species list, damage agents, and the Southwest Variant / Woodland Nested Plot setting. It does not include plot records, tree records, woodland records, regeneration records, Crew Name, or Crew ID.

Add Or Select A Plot

  • Use New plot # and Add to create a plot.
  • Use the Current Plot dropdown to switch between plots.
  • Any tree, woodland, or regeneration record you save goes to the currently selected plot.

Enter Site Data

The Site tab is for plot-level reference information. Plot Weasel Desktop does not use Site.csv for tree calculations, but the forester may need the site data for review, master records, or project notes.

  • Fill in the fields that are available and useful.
  • Enter elevation as actual feet, such as 2500.
  • If slope is 5% or less, Aspect will only allow Level. If slope is greater than 5%, Level is not available.
  • At plot center, use Capture GPS 30 sec to collect device GPS fixes for about 30 seconds. The app averages the fixes and fills in whole-meter UTM Easting, UTM Northing, and UTM Zone.
  • If the device returns GPS altitude, the same capture fills Elevation as whole feet. Some tablets and browsers do not return altitude, so crews can still type elevation manually.
  • GPS Fix Count is the number of location readings collected during the capture. A higher number usually means the average had more readings to work from.
  • The tablet must have Location turned on, and the app or browser may ask for location permission. GPS capture does not need internet or cloud sync.
  • If GPS does not work or a crew has coordinates from another device, type the UTM values manually.
  • It is okay if some site fields are blank.
  • The app saves site information locally as you work.

Enter Tree Data

  1. Go to the Trees tab.
  2. Use the species filter if the dropdown is long.
  3. Select the species.
  4. Select whether the tree is Live or Dead.
  5. For a normal live tree, enter DBH and Height. Leave Actual Height blank.
  6. When Broken Top is selected in either damage-agent field, enter the estimated total height in Height and enter the actual height to the broken top in Actual Height.
  7. For a dead tree, DBH may be blank. Height may be blank only when Actual Height is blank and Broken Top is not selected.
  8. Dead-tree Actual Height is optional. When it is entered, Height is also required and Actual Height must be less than Height.
  9. Choose Damage Agent 1 when damage is present.
  10. Choose Damage Agent 2 only when a second, different damage agent applies.
  11. Leave both damage fields as None when no damage agent was observed.
  12. Enter cull, crown ratio, age, decay class, status, and notes as appropriate.
  13. Decay Class uses codes 1 through 5, can only be used when the tree status is Dead, and exports as DECAYCD.
  14. DBH values are stored and exported with one decimal place. Entering 10 becomes 10.0, entering 10.3 stays 10.3, and entering 103 becomes 10.3 when the user leaves the field.
  15. Click Save Tree Record.

Tree validation rules:

  • Live tree DBH is required and must be 5.0 inches or greater.
  • Live tree Height is required and must be 8 feet or greater.
  • Dead-tree DBH is optional. If entered, it must be a valid number and must be 5.0 inches or greater.
  • Dead-tree Height is optional unless Broken Top is selected or Actual Height is entered. If Height is entered, it must be 8 feet or greater.
  • Species, DBH, and Height are required for a measured tree row to be included in PlotWeasel_upload.csv.
  • Damage Agent 2 is optional.
  • The same named damage agent cannot be selected in both tree damage fields.
  • If Broken Top is selected in either damage-agent field, both Height and Actual Height are required.
  • For Broken Top, Height is the estimated total height and Actual Height is the actual height to the broken top.
  • Whenever Actual Height is entered, it must be greater than zero and less than Height.
  • Dead trees require Decay Class 1 through 5.
  • Cull, Crown Ratio, and Age are disabled for dead trees.
  • If cull is entered, it must be between 0 and 100.
  • If crown ratio is entered, it must be between 0 and 100.
  • If age is entered, it must be between 0 and 1000.

Decay Class Labels

Class 1 Recently dead; bark and fine branches intact; wood hard.
Class 2 Some bark loss; fine branches gone; wood firm.
Class 3 Bark mostly gone; top often broken; wood starting to soften.
Class 4 No bark; wood soft; form degrading.
Class 5 Very soft, crumbling; snag collapsing or stump-like.

How Actual Height works: For a normal live tree, enter Height and leave Actual Height blank. When exporting to Plot Weasel Desktop, Field Logger uses Height for both ht and actualht. When Broken Top is selected in either damage-agent field, Height is the estimated total height the tree would have had and Actual Height is the actual height to the broken top. Actual Height must be less than Height. For a dead tree, Actual Height is optional; when it is entered, Height must also be entered and the same Actual Height less-than-Height rule applies.

Enter Woodland Data

Fixed radius only: The Woodland tab is for trees measured on the fixed-radius woodland nested plot. Woodland records are stored separately from trees tallied in the point sample.

  1. In the Field Session panel, select Activate Southwest Variant / Woodland Nested Plot.
  2. Go to the Woodland tab. The title displays fixed radius only.
  3. Select a species from the hardcoded Southwest woodland species list.
  4. Select Live or Dead.
  5. Enter Diameter at Root Collar (DRC). Use ERDC when the tree is forked at ground line.
  6. Select Form Class 1 for a single stem or Form Class 2 for multiple stems or a tree forked at ground line.
  7. Enter Height. Woodland records do not use Actual Height or Cull.
  8. Enter Crown Ratio, Age, damage agents, and Notes when applicable.
  9. For a dead woodland tree, select Decay Class 1 through 5. Crown Ratio and Age are not used for dead woodland records.
  10. Click Save Woodland Record.

Southwest Woodland Species

Tab-specific species codes: The Trees and Woodland tabs intentionally maintain separate species mappings because the two workflows use different measurements and volume equations. Always use the species name and code displayed by the tab where the record is being entered.

Do not replace a Trees-tab species code with a Woodland-tab code or replace a Woodland-tab code with a Trees-tab code. Use the Trees tab for DBH point-sample records and the Woodland tab for DRC fixed-radius records. Do not enter the same sampled tree on both tabs.

Choose one sampling method before field collection: Users need to decide how each of the following woodland species will be sampled. Occasionally, these species have well-defined single stems that allow measurement at DBH as part of a point sample. More often, these species are measured at Diameter at Root Collar (DRC) on a fixed-radius woodland plot.

Be aware that an overlap species may be available through both the Trees and Woodland workflows. Once the project lead selects a sampling method, measure and record that species using only the corresponding method and tab: Trees for DBH point-sample measurements or Woodland for DRC fixed-radius measurements. Do not record the same sampled tree on both tabs.

Woodland validation rules: Live woodland trees require DRC and Height. Form Class 1 or 2 is required for every woodland record. Dead woodland trees require Decay Class 1 through 5. Actual Height and Cull are not collected on the Woodland tab.

Enter Regeneration Data

  1. Go to the Regen tab.
  2. Select a species from the project species list.
  3. Enter Stem Count.
  4. Select Diameter Class and Height Class if applicable. Use 0 inch for seedlings.
  5. Select one damage agent when damage is present.
  6. Leave the damage-agent selection as None when no damage agent was observed.
  7. Add notes if needed.
  8. Click Save Regen Record.

Regen validation rule: If Diameter Class is 2 inch or 4 inch, Height Class must be >5 ft.

Regen damage-agent export: Regen.csv uses the column name damage_agent. A selected named agent, such as Insects, is written to that field. None or a missing damage value exports as a completely blank cell.

Record Tree And Regen Null Plots

Tree and regeneration null plots are handled independently.

  • A tree null plot is a plot with no saved tree records.
  • A regen null plot is a plot with no saved regeneration records.
  • A plot can contain tree records and still be a regen null plot.
  • A plot can contain regen records and still be a tree null plot.
  1. Add the plot number to Field Logger.
  2. Fill in any site information that is available.
  3. Enter the tree records actually observed.
  4. Enter the regeneration records actually observed.
  5. When a category has no observations, do not create a fake record for that category.
  6. Export normally.

Field Logger creates export-only placeholder rows automatically:

  • For a plot with no trees, PlotWeasel_upload.csv receives one row containing the plot number and blank tree fields.
  • For a plot with no trees, Tree.csv receives one null row.
  • For a plot with no regeneration, Regen.csv receives one null row.
  • The Regen.csv null row has blank species, stem count, diameter class, height class, and damage_agent fields.
  • The Regen.csv Notes field identifies the row as Null plot - no regen records.
  • Null rows are created during export only. They do not appear as saved records in the Logger and do not increase the Tree or Regen count shown in the app.
  • Once a real tree or regen record is saved for the plot, that category's null row disappears from the next export.

Use The Review Tab

The Review tab helps catch issues before exporting.

  • Error means something should be fixed before exporting.
  • Warning means something may be okay, but should be checked.
  • Click a Review item to reopen the related plot, tree, woodland, or regeneration record when possible.
  • Tree, woodland, and regeneration review items use labels such as Plot 1 Tree 2 or Plot 1 Woodland 1 so the record is easier to find.
  • Broken Top is checked in either tree damage field.
  • Use Refresh Review after changes if needed.

Merge Multiple Crews

  1. Each crew exports a Crew Package.
  2. Move those Crew Package files to the secured office computer.
  3. Open Field Logger on the office computer.
  4. Go to Export / Merge.
  5. Use Import Crew Package and select one or more crew package files.
  6. Review the merge summary.
  7. Use Save Site, Tree, Woodland, Regen CSVs for the combined Site, Tree, and Regen CSVs.
  8. Export the Plot Weasel Desktop CSV separately for the tree calculator.
  9. Confirm the combined exports contain both tree damage-agent columns and the regen damage_agent column.
  10. Confirm plots without tree or regen records have the correct null rows.

Move Work To Another Tablet

Use this when a tablet is down but you can still open Field Logger and export its data.

  1. On the original tablet, go to Export / Merge.
  2. Export a Crew Package.
  3. Move that Crew Package JSON to the replacement tablet using an approved local transfer method.
  4. On the replacement tablet, go to Export / Merge and choose Import Crew Package.
  5. If you import one Crew Package, Field Logger uses the package's Project Name, Crew Name, and Crew ID when the receiving tablet is blank. If the receiving tablet already has different values, the app asks before changing them.
  6. If you import multiple Crew Packages at once for office merging, Field Logger does not change the receiving device's Project Name, Crew Name, or Crew ID.
  7. Existing tree records with only one stored damage agent remain valid. Their second damage-agent field is blank.

Tree Analysis Export Contract

Field Logger creates PlotWeasel_upload.csv with the following columns:

plot, record_type, spp, dbh, drc, form_class, ht, actualht, cull, DECAYCD, crown_ratio, status, damage_agent, damage_agent_2, species_name, crew_id, source_record_id, project_name, crew_name

  • The current Desktop source uses fixed column names rather than the former v2.0.0 column-mapping screen.
  • Do not rename or change the capitalization of the standard analysis columns before upload.
  • The export contains qualifying point-sample Tree records only. Woodland records are excluded.
  • Measured rows use record_type=tree.
  • drc and form_class are blank on point-sample tree rows.
  • damage_agent contains the first tree damage-agent name.
  • damage_agent_2 contains the optional second tree damage-agent name.
  • Trees with no damage agents have blank values in both damage-agent fields.
  • A plot with no qualifying point-sample tree records is represented by a row containing the plot number, record_type=tree, and blank measurement fields.

Regeneration Export Contract

The current Desktop Regen source expects these standard fields:

plot, spp, Stem Count, Diameter Class, Height Class, damage_agent

  • A named regeneration damage agent is written to damage_agent.
  • No damage agent is represented by a blank damage_agent cell.
  • Field Logger preserves a real sampled plot number on a regeneration null row and leaves the regeneration measurement fields blank.

Problem What To Try
Android app says Memory only. Do not use that build for real field collection. Export Backup JSON immediately if important data was entered. Install the official Android Studio-built APK or rebuild from the Android source and confirm the header says Local only.
Android app says Local only. This is the expected storage mode for field use. Still run the storage test: create a test project, close the app, reopen it, and confirm the project remains.
Android or Play Protect warns that the APK is unknown or unrecognized. A directly installed internal APK may produce this warning because it did not come from Google Play. Only continue when the APK came from the approved Plot Weasel release source and its SHA-256 value matches the published value. For managed tablets, IT may need to approve or deploy the APK. This warning is separate from file exporting.
Android says App not installed during an update.
An Android export button appears to do nothing, or the app says Folder save cancelled. Confirm the installed app header shows v2.3.4. Then check My Files → Downloads → PlotWeasel. In the v2.3.4 Android APK, exports should use the native AndroidFileBridge rather than the browser folder picker. A Folder save cancelled message usually means an older APK was installed or the APK was built without the current MainActivity.java bridge. Do not uninstall the app. Build and install a correctly signed higher-version update over the existing installation.
An Android success message appears, but the exported file cannot be found. Open My Files → Downloads → PlotWeasel. Individual JSON and CSV files are directly inside PlotWeasel. The grouped Site, Tree, Woodland, Regen export is inside a dated project-and-crew subfolder. Search My Files by part of the project name when needed.
Export Backup JSON before uninstalling anything. The new APK may have a different signing key, app identity, or version code.
The tablet asks which app to use. Choose the normal browser. Android treats a loose HTML file like a document unless an APK wrapper is used.
The app icon looks like a browser or document icon. The browser tab and home-screen manifest use the paw icon, but Android file managers may still show a generic document icon for loose HTML files.
A Python or firewall/admin popup appears during testing. Cancel it. The shareable app does not need Python. That popup usually comes from a local preview server used during testing.
Species are not showing in the Tree or Regen dropdown. Go to the Species tab and add species from the FIA Master Species list. Each project starts with an empty species pick list.
A tablet needs the same project species list as another tablet or office computer. On the source device, use Export Project Setup. On the receiving tablet, use Import Project Setup. Then enter that tablet's Crew Name and Crew ID.
A needed damage agent is not in the Tree or Regen dropdown. Go to the Species tab, add the name under Project Damage Agents, and return to the Tree or Regen tab.
A tree will not save after selecting two damage agents. Make sure Damage Agent 1 and Damage Agent 2 are different. Leave Damage Agent 2 as None when only one damage agent applies.
Broken Top will not save. Broken Top in either damage field requires both Height and Actual Height. Enter the estimated total height in Height and the actual height to the broken top in Actual Height. Actual Height must be greater than zero and less than Height.
DBH will not save. For live trees, check that DBH is 5.0 inches or greater. Dead trees can leave DBH blank. DBH exports with one decimal place when entered. Typing 10 becomes 10.0, and typing an implied decimal value such as 103 becomes 10.3.
A dead tree will not save. Select Decay Class 1 through 5. DBH may be blank. Height may be blank when Actual Height is blank and Broken Top is not selected. When Actual Height is entered, Height is also required and Actual Height must be less than Height. Cull, Crown Ratio, and Age are disabled for dead trees.
The CSV contains the word None in a damage-agent field. Confirm the newest Field Logger HTML or APK is being used, then export a new CSV. The updated exports write blank damage cells instead of None.
The second tree damage agent is missing from PlotWeasel_upload.csv. Reopen the tree record, confirm Damage Agent 2 is selected, save the record again, and export a new Plot Weasel Desktop CSV. Confirm the header includes damage_agent_2.
A regen record with 2 inch or 4 inch diameter will not save. Select the >5 ft Height Class.
Regen.csv does not show a plot that had no regen records. Confirm the plot number was added to the Field Logger plot list. Export a new Site, Tree, Regen CSV folder and look for a plot-only Regen.csv row whose Notes field says Null plot - no regen records.
Regen.csv shows a blank damage_agent cell. This is expected when the regen record used None or had no damage-agent value.
Desktop does not include a plot with no trees. Make sure the CSV includes a plot-only row with blank tree fields. Field Logger creates this row automatically for plots with no qualifying tree records.
Field Logger opens, but tabs, Add Plot, Aspect, or Slope Position do not work. Open the official v2.3.4 self-contained PlotWeasel_Field_Logger.html file in Microsoft Edge from local device storage. Do not run it from a Teams, SharePoint, email, or cloud preview.
Windows says the Site, Tree, or Regen export is harmful. Use Save Site, Tree, Woodland, Regen CSVs in Microsoft Edge. The folder-save workflow avoids the older sequence of individual browser downloads.
Plot Weasel Desktop rejects PlotWeasel_upload.csv or reports missing columns. Confirm that the file was created with the Field Logger Plot Weasel Desktop CSV export. Do not rename the standard fields. Confirm that the header includes plot, spp, dbh, ht, actualht, cull, DECAYCD, crown_ratio, status, damage_agent, and damage_agent_2. For Desktop-specific errors, use Casey Sigg's current Desktop documentation or support contact.
A numbered regeneration null plot produces a missing or NA result in Plot Weasel Desktop. Do not rely on that Regen result until compatibility is confirmed. Field Logger writes the actual plot number with blank regen fields, while the supplied Desktop v2.3.3 source currently checks for the literal word null in the plot field. Report the file and plot number to the Desktop maintainer.

Plain-English File Glossary

  • Android APK: The installable Android application file. For this release, the official filename is PlotWeaselFieldLogger_Ver2.3.4.apk.
  • APK installer file: The file tapped to install or update the app. It can be deleted from Downloads after installation without deleting the installed application or its saved records.
  • Local only: The expected Field Logger storage mode. Data is stored locally on the device until exported, deleted, or cleared.
  • Memory only: A temporary storage mode. Do not use it for operational field collection because records may disappear when the app closes or reloads.
  • Android export folder: The My Files → Downloads → PlotWeasel location used by the v2.3.4 Android APK for JSON, CSV, and TXT exports.
  • Project Setup: A JSON file used to copy project settings to crew tablets. It does not contain field records, Crew Name, or Crew ID.
  • Crew Package: A JSON file used to merge one crew's active-project data into another Field Logger installation or move work to a replacement tablet.
  • Backup JSON: A JSON backup of the active project only. Export one Backup JSON for every project stored on the device.
  • PlotWeasel_upload.csv: The point-sample tree calculation file for Plot Weasel Desktop. It includes qualifying point-sample tree rows and tree null-plot rows. It does not include woodland records.
  • Site.csv: Site-level reference information, including UTM and GPS fields when captured.
  • Tree.csv: Point-sample tree records for reference and master records. It contains the original Live/Dead field, the lowercase status field, both tree damage-agent fields, and tree null rows.
  • Woodland.csv: Fixed-radius woodland nested-plot records. It is separate from the point-sample PlotWeasel_upload file.
  • Regen.csv: Regeneration records and export-only regeneration null rows.
  • Review.txt: The current Review messages generated by Field Logger.
  • Plot Weasel Desktop: A separate hosted Shiny R analysis application developed, hosted, and maintained by Casey Sigg. The Field Logger project does not maintain its hosting, calculations, interface, releases, or user support.

  • Update the Field Logger version number and release date.
  • Update the official Field Logger APK filename and SHA-256 checksum.
  • Add new Field Logger buttons, fields, validations, and exports.

  • When Desktop changes, test PlotWeasel_upload.csv before changing the listed compatibility target.
  • Test one tree with no damage, one damage agent, and two damage agents.
  • Test Broken Top in both tree damage-agent positions.
  • Test a tree null plot in PlotWeasel_upload.csv.
  • Test measured regeneration records in Regen.csv.
  • Test a numbered regeneration null plot and confirm it contributes zero, not NA, in the Desktop result.
